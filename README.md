# Mitrayah 3D Printing Website

A responsive, single-page HTML/CSS/JavaScript website for Mitrayah 3D Printing.

## Files

- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and WhatsApp enquiry form

## Before publishing

Open `script.js` and replace:

    const whatsappNumber = "91XXXXXXXXXX";

with the real WhatsApp number, using country code and digits only.

Then open `index.html` and replace:

- `YOUR_EMAIL@example.com`
- `YOUR_INSTAGRAM`

You can also replace the sample gallery cards with your actual product photos.

## Local preview

Double-click `index.html`, or open it in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Commit the files.
4. Go to Settings → Pages.
5. Select the main branch and root folder.
6. Save. GitHub will provide the website URL.

No server or database is required.
